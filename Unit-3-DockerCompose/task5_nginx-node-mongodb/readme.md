# Nginx + Node.js + MongoDB

## Objective
Run a multi-service application using Docker Compose.

## Services Used
- Nginx
- Node.js Backend
- MongoDB

## Steps Performed
- Created backend service
- Added MongoDB database
- Added Nginx web server
- Started all services using Docker Compose

## Learning
- Docker Compose manages multi-service applications
- Services communicate through internal networking
- Containers can run frontend, backend, and database together

## Key Insight
Docker Compose simplifies orchestration of microservice-style architectures.

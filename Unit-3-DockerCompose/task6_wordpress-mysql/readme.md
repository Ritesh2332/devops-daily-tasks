# WordPress + MySQL with Docker Compose

## Objective
Deploy WordPress connected to a MySQL database using Docker Compose.

## Services Used
- WordPress
- MySQL

## Steps Performed
- Created docker-compose.yml
- Configured database environment variables
- Started services using Docker Compose
- Accessed WordPress through browser

## Learning
- Docker Compose simplifies multi-container deployments
- Containers communicate using service names
- Environment variables configure application services

## Key Insight
Docker Compose enables rapid deployment of interconnected application stacks.

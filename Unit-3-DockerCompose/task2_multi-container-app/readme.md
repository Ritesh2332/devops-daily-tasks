# Multi-Container Application

## Objective
Run multiple connected services using Docker Compose.

## Services Used
- Node.js Backend
- Nginx

## Steps Performed
- Created backend application
- Dockerized backend service
- Defined services in docker-compose.yml
- Started all containers together

## Learning
- Docker Compose simplifies multi-container management
- Services can be built and started together
- Compose automatically creates networking between services

## Key Insight
Multi-container applications can be managed using a single YAML configuration.

# Environment Variables with Docker Compose

## Objective
Pass environment variables to containers using Docker Compose.

## Steps Performed
- Created Python application
- Used .env file for configuration
- Passed variables using docker-compose.yml
- Verified dynamic output changes

## Learning
- Environment variables separate configuration from code
- Docker Compose supports external env files
- Applications can adapt without code modification

## Key Insight
Using environment variables improves flexibility and portability of containerized applications.

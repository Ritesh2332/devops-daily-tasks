# Docker Volumes

## Objective
Store persistent data using Docker volumes.

## Steps Performed
- Created Docker volume
- Mounted volume inside container
- Stored data in volume
- Deleted container
- Verified data persistence using a new container

## Learning
- Volumes persist independently of containers
- Data survives container deletion
- Volumes are used for databases and persistent application storage

## Key Insight
Docker volumes separate application data from container lifecycle.

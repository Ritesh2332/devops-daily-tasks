# Port Mapping and Web Application

## Objective
Expose a containerized web application to the browser using Docker port mapping.

## Steps Performed
- Ran Nginx container
- Mapped host port 8080 to container port 80
- Accessed application through browser
- Verified logs and container status

## Learning
- Containers use internal ports
- Port mapping exposes services externally
- Docker allows host-to-container communication using mapped ports

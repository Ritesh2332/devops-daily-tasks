# Bind Mounts

## Objective
Synchronize files between host machine and Docker container using bind mounts.

## Steps Performed
- Created local file on host
- Mounted local directory into container
- Accessed host file inside container
- Created file inside container
- Verified file appeared on host machine

## Learning
- Bind mounts directly connect host directories to containers
- Changes sync instantly between host and container
- Commonly used in development environments

## Key Insight
Bind mounts provide real-time file sharing between the host and container.
